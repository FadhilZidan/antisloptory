- `antislop-ending`: pemotongan dua kalimat terakhir, penolakan resolusi rapi, penutup pada benda fisik.
- `references/anti-patterns.md` dan `references/examples.md`.
- Installer interaktif (`npx github:FadhilZidan/antisloptory`) dengan target Antigravity, workspace, Claude Code, dan path kustom.
- Manifest plugin Claude Code.
